Customer setup steps
  1. Disable Windows Defender temporarily
  2. Disable Secure Boot in BIOS
  3. Run OmnisLauncher.exe as Administrator
  4. Enter their license key when prompted
  5. Launch CS2 — press INSERT for menu
Reseller tips
  • Start customers on the 3-day trial
  • Always recommend a secondary account
  • Update them when new features drop
  • Keys are single-use — do not share
