Admin Guide
How to manage your reseller network
Adding New Resellers
Go to your Discord Server and assign the Reseller Role (the Role ID configured in Vercel as DISCORD_RESELLER_ROLE_IDS) to the user you want to add.

Once they have the role, they can click "Reseller Login" on the main website and instantly access the dashboard. If you remove their Discord role, their access is instantly revoked — no manual work needed.
Revoking Access
Simply remove the Reseller Role from the user in your Discord server. Their existing JWT token will still work until it expires (7 days), but they won't be able to get a new one. For immediate revocation, you can rotate the JWT_SECRET in Vercel — this invalidates all existing sessions.
Environment Variables Reference
DISCORD_CLIENT_ID — Your Discord OAuth app Client ID
DISCORD_CLIENT_SECRET — Your Discord OAuth app Client Secret
DISCORD_BOT_TOKEN — Bot token for checking guild member roles
DISCORD_GUILD_ID — Your Discord server ID
DISCORD_RESELLER_ROLE_IDS — Comma-separated role IDs for resellers
DISCORD_ADMIN_ROLE_ID — The admin role ID (your role)
JWT_SECRET — Secret for signing auth tokens
SELLAUTH_API_KEY — Your SellAuth API key
SELLAUTH_SHOP_ID — Your SellAuth shop ID
